최종 설계 검토 출처
이 클라우드는 새 모델 검토를 성공 호출하지 못했다. 아래는 원래 작업 스레드가
실제 로컬 CLI 호출 후 사용자 메시지로 전달한 결과다. 로컬 인증은 복사하지 않았다.
- agy1.4.12 / gemini-4-argon-high / high: 첫 검토 약168초 완료로 전달.
- Claude Code2.1.284 / claude-fable-5 / high: 이미지·텍스트 읽기 도구, 약111초로 전달.
- Fable 반론 후 Argon 마지막 합의 확인 완료라는 최종 메시지를 수신했다.
- 원문 CLI 로그/사용량 파일은 이 클라우드에서 독립 확인하지 않았다.

채택: 실제 모듈 PBR 메시+독립 차량+바닥/충돌 분리, Standard+박스 반사 프로브.
근접 차폐/가까운 차3대/바닥에 조명·노출·하늘 채도·아스팔트 톤을 동급으로 평가.
수목·차량 실제 그림자 우선. 쿠키는 광향/위치 일치 시 보조 가능하나 이번에는 추가 안 함.
우측 비움/좌측6~7대/20×28m/통로6m/면2.5×5m는 설계치이며 법적 검증 완료 아님.
사람 눈높이1.65m, 근경 차량3~4m, 수직FOV37~44도는 실제 나란히 비교 후 확정.
정지+전진10m+좌우3m, 가림/시차/톤 검증. AI 이미지 오류는 재현 대상 아님.
이미지 평면 대체, 무허가 로드뷰 재구성, 미세 셰이더 반복은 채택하지 않음.
현대차 고품질 대표 모델 미확보. 리핑/라이선스/가상 번호판 개별 검수 필요.
다른 씬·공용 자산·ProjectSettings·Packages/manifest.json 보호.
소프트웨어 Unity 렌더도 시각평가에 사용 가능하나 GPU/Android 실시간 성능 증거 아님.
실제 환경 장애는 Unix 소켓 EPERM+Unity CDN 정책 차단+라이선스 미활성화.
오프라인 C# 컴파일은 Unity 씬 동작/렌더 검증이 아님.
