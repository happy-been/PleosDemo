필요한 최소 사용자/환경 조치
1. 실행환경 제공 측에서 Unity 정상 IPC(Unix socket)와 공식 인증/라이선스 호스트 통신,
   사용자에게 공식 로그인·약관 확인을 안전하게 인계할 수단을 지원해야 함.
   현재 제공된 도구로 이 소켓/네트워크 정책을 바꾸거나 Hub 인증 UI를 제공할 수 없음.
2. 지원 환경에서 Unity Hub에 본인 로그인. Personal 사용 자격/약관을 본인이 확인.
   공식 안내:Settings>Licenses>Add license>Get a free personal license(필요할 경우).
   2022.3 기존 안내는 Hub 경로다. 최신 공식 Unity CLI 문서에는 별도로
   unity auth login 및 unity license activate --personal --accept-eula 경로가 있다.
   따라서 모든 Personal 활성화가 GUI Hub 전용이라고 일반화하지 않는다.
   최신 CLI와 이2022.3.16f1 Editor의 실제 호환성/실행은 여기서 미검증이다.
   사용자가 약관을 확인해야 하며 이 작업에서 --accept-eula를 실행하지 않았다.
   https://github.com/Unity-Technologies/skills/blob/main/skills/unity-cli/references/auth-license-cloud.md
   ALF 우회나 로컬 라이선스 복사는 하지 않음.
   https://docs.unity.com/en-us/hub/manage-license
   https://docs.unity3d.com/2022.3/Documentation/Manual/ManagingYourUnityLicense.html
3. 클라우드CLI도 쓰려면 동일 클라우드 터미널에서 agy 실행 후 공식 OAuth URL을
   개인 브라우저에서 열고, 돌아온 일회 코드를 해당 터미널의 공식 프롬프트에 입력.
   https://antigravity.google/docs/install?tab=cli
4. Claude 기존 구독은 claude auth login --claudeai의 공식 브라우저 흐름 사용.
   https://code.claude.com/docs/en/authentication
   현재 채팅에는 안전한 터미널 인증코드 입력/Unity Hub 화면 인계수단이 확인되지 않음.
   비밀번호/토큰을 채팅에 보내거나 기존PC 인증파일을 복사하지 말 것.
