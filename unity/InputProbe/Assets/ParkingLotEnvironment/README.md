# 한국 공영주차장 맵

이 폴더는 **주차장 맵 전용**입니다. 오늘 작업은 앱 화면이나 자동차 입력 연동이 아니라 Unity 안에서 보이는 주차장과 주변 환경입니다.

## 열어서 보기

1. Unity Hub에서 `C:/dev/PleosDemo/unity/InputProbe`를 Unity **2022.3.16f1**로 엽니다.
2. Project 창에서 `Assets/_Parkside/Scenes/ParklingLot.unity`를 더블클릭합니다. 현재 파일명의 철자가 `ParklingLot`인 것은 기존 이름을 유지한 것입니다.
3. 위쪽 ▶ 버튼을 누르고 Game 화면 안을 한 번 클릭합니다.
4. 숫자 **2**는 사람 눈높이, **3**은 차량 가까이, **4**는 위에서 내려다보기, **5**는 느린 항공 카메라 이동, **6**은 반대쪽 눈높이입니다. **1**은 낮은 대각선 시점입니다.
5. 자유롭게 둘러보려면 마우스 오른쪽 버튼을 누른 채 **W/A/S/D**로 이동합니다. **Q/E**는 아래/위, **Shift**는 빠르게 이동입니다. ▶ 버튼을 다시 누르면 편집 상태로 돌아옵니다.

이 키들은 맵을 둘러보는 카메라입니다. 실제 차량 운전 기능과 구분합니다. Play 모드에서 움직인 카메라는 실행을 끝내면 원래 편집 위치로 돌아옵니다.

가까운 나무와 관목에는 아주 약한 잎 움직임을 넣었습니다. `ParkingLot_PreviewCamera`의 `Foliage Wind Strength`를 0으로 두면 끌 수 있습니다. 카메라에 붙은 `ParkingLotFoliageBounds`는 흔들리는 잎이 화면 가장자리에서 잘리지 않게 표시 범위를 보정하므로 함께 유지합니다.

최신 저장 맵은 **v35**(2026-11-02 15:57)입니다. 한국 주택가 배경, 현대 차종 26대와 소형 트럭 2대, 촬영 자료를 쓴 보도 표면, 약한 나뭇잎 움직임, 주변 골목의 전봇대 5개와 연결선을 포함합니다. v30에서 전체 노면과 명암을 조정한 데 이어, v31에서는 차량에 조각처럼 비치던 반사를 부드럽게 바꿨습니다. 주변 주택은 3층 6동·4층 14동·5층 5동으로 구성해 같은 높이의 반복을 줄였습니다. 창문 비율은 유지하며 옥상과 충돌 범위도 높이에 맞췄습니다. 도로에 걸치던 외곽 주택 한 동은 담장·바닥과 함께 안쪽으로 옮겼습니다. v32에서는 실제 촬영한 넓은 아스팔트 표면을 적용했습니다. 가까운 바닥의 작은 입자는 유지하고, 항공에서는 자연스러운 균열과 마모가 보이도록 조정했습니다. v33에서는 나무·관목·화단의 과한 흰 반사를 줄여 녹지 색과 명암을 자연스럽게 맞췄습니다. 원본 사진·형상·배치는 유지했습니다. v34에서는 먼 산비탈에 크기와 색이 다른 수관층을 추가해 매끈한 산 표면의 모형 느낌을 줄였습니다. 기존 이미지 한 장을 재사용하며 원래 지형과 차량·주택 배치는 유지했습니다. v35에서는 아이오닉 5 앞유리의 투과와 실내면 반사를 조정했습니다. 옆/뒤유리와 원본 형상은 유지했습니다.

저장 후 재열기·재질/셰이더 오류 0·보호 파일 검사를 통과했습니다. 건물 32동과 도로 13곳, 나무 위치의 겹침 검사도 통과했습니다. v28에서 측정한 현재 노트북의 Full HD Unity Game 화면은 항공 약 35.4fps, 눈높이 약 33.8fps입니다. v31~v35의 실제 Game 화면 성능은 별도 측정하지 않았습니다. v34 숲 추가 비용만 같은 조건의 오프라인 렌더로 비교했습니다. Android 실행 성능과는 별개이며 실사 촬영과 동일한 품질을 달성한 상태는 아닙니다.

최신 검증 영상은 `korean-parking-v31.mp4`(항공 8초), `korean-walkthrough-v34.mp4`(눈높이 8초), `korean-utility-native-v28.mp4`(골목 4초)입니다. 항공 영상은 v31, 눈높이 영상은 v34, 최신 스틸은 v35, 골목 영상은 v28입니다. 앞의 두 영상은 4K 렌더를 Full HD로 줄였고, 골목 영상은 Full HD 직접 렌더로 먼 전선의 움직임을 확인합니다. `tucson-glazing-orbit-v24.mp4`는 이전 버전의 임시 복제 차량 유리 검사 영상입니다.
